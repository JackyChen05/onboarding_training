# 1.6 Wi-Fi 关键指标（吞吐 / 覆盖 / 漫游 / 并发）

## 先说清楚一件事

「Wi-Fi 快不快」不是测试判据。判据必须写清：什么帧长？多远？几个终端？开没开加密？（手册 1.5 判定准则五要素：观测量 + 测量方法 + 判定门限 + 样本量 + 环境条件。）

部门 Wi-Fi 性能测试的标准方法是 **TR-398**（Broadband Forum《Wi-Fi In-Premises Performance Testing》），在可控射频环境（屏蔽房 + 程控衰减器）下执行，保证结果可复现、可比。知识库有《TR-398中文执行要点》与配套的 SUITE TEST REPORT 模板。

## 四大指标

### 吞吐（Throughput）

- **测量**：IxChariot / TestCenter 打流，分别测 TCP 上下行、多流并发。
- **判据要点**：标注频段（2.4G/5G/6G）、带宽（20/40/80/160MHz）、加密方式、终端能力与距离/衰减值。
- **陷阱**：实验室开阔环境测出的极限值与用户家弱电箱环境没有可比性——实验室数据的价值是**可比性**（版本间、竞品间），不是外推用户体验（手册 3.2.3）。

### 覆盖（Coverage）

- **测量**：多点位 + 程控衰减模拟距离，记录各点吞吐/RSSI。
- **典型失效**：高温下 Wi-Fi 降功率——夏天变慢，实验室常温空载复现不出（手册 3.2.4）。覆盖测试要考虑温度维度。

### 漫游（Roaming）

- **测量**：移动中 ping/打流，统计切换时延与丢包；802.11 k/v/r 辅助漫游是重点协议。
- **判据**：漫游成功率必须给样本量——写「94%（47/50）」，不写「94%」（手册 1.5.3 概率型指标）。
- 知识库《15、802.11 kvr协议讲解》《14、802.11 Beacon帧字段详解》是这两块的专题资料。

### 多终端并发（Multi-STA）

- **测量**：几十台终端同时关联 + 混合流量，观察是否有个别终端被「饿死」（完全没速率）。
- **典型失效**：并发无线终端超过规格后新终端连不上或老终端掉线——资源边界问题，要测超过边界之后的行为（手册 2.2.5）。
- 部门环境：大/小屏蔽房 + OCTOBOX + 手机阵列，支持多终端并发与自动化执行（知识库《17、Octobox自动化测试指导及注意事项》）。
