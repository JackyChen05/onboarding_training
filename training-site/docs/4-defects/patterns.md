# 4.2 缺陷模式分类

## 最高维度的分类：三交叉框架

最凶的缺陷长在三个维度的交叉处（手册 2.3）：

| 维度 | 内容 |
| --- | --- |
| 资源边界 | NAT 表项、并发连接、组播组数、解码器实例、Mesh 节点、内存/存储 |
| 时间累积 | 内存/句柄泄漏、内存碎片、计数器回绕、时钟漂移、闪存磨损 |
| 异常路径 | 掉电、断纤、拔线、服务超时、升级中断、看门狗盲区 |

写用例时机械地问一遍这个组合矩阵，能挖出大量没人想到的路径。

## 接入产品高频缺陷模式

（来自手册 3.2.4，都是真实缺陷模式）

| 失效模式 | 典型现象 | 为什么容易逃逸 |
| --- | --- | --- |
| 写 Flash 时掉电 | 反复拉电后配置丢失/启动失败 | 拉电测试在空闲态做，避开写窗口 |
| 高温 Wi-Fi 降功率 | 夏天变慢 | 常温空载机箱测试 |
| PMTU 黑洞 | 能 ping 通但网页打不开 | 小包 ping 掩盖问题 |
| NAT 会话表耗尽 | P2P 时网页打不开 | 并发数远低于规格 |
| IPv6 前缀续租失败 | 数天后 IPv6 静默失效 | 只测初次获址 |
| 组播组老化超时 | 几分钟一次花屏 | 测试时长短 |
| 硬件加速绕过 QoS | 限速不生效、统计不准 | 加速默认开，从不做开关对比 |
| WPA2/3 过渡兼容 | 老终端连不上 | 测试终端都是新机型 |
| OTA 断电变砖 | 升级失败无法开机 | 断电点避开危险窗口 |
