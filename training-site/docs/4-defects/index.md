# 4. 缺陷库 · 模块总览

试用期硬指标：项目实践阶段**累计提交有效缺陷 ≥ 10 个**（有效 = 开发确认并修复），且**提交时附完整证据链**。这个模块的目的：你提交的第一个缺陷就要是合格的。

## 为什么缺陷是部门最重要的资产之一

手册 1.4.1 讲「会怎么坏」时列了三个方法，第一条就是**缺陷模式库**——把历史上所有出过的缺陷抽象成「模式」，形成清单。你想不到的，别人可能已经踩过。你提交的每一个合格缺陷，都在为这个库增加弹药；反过来，写用例前先查缺陷模式库，是避免「测试无效」的最有效手段。
