# 2.3 CAS / DRM 与 HDMI / HDCP

## CAS / DRM：内容保护

| 体系 | 适用场景 | 关键点 |
| --- | --- | --- |
| CAS（条件接收） | 广电 DVB 直播 | 智能卡/无卡 CA，解扰 TS 流 |
| DRM | IP/OTT 内容 | Widevine、PlayReady、ChinaDRM |

测试关注点：

- **安全等级**：Widevine L1（硬件安全）才能播高清，L3 只有标清。典型缺陷：DRM 安全等级降级——某些平台只能看标清，只验证「能播」就漏掉了（手册 3.3.3）。测试必须验证实际安全等级，不只是「能出画面」。
- **授权链异常**：授权服务器超时、授权过期、离线授权——都要测。
- **合规属性**：内容保护认证（Widevine/PlayReady/ChinaDRM）不过 = 内容方不授权，高清内容不可播——二值闸门（手册 2.2.7）。

## HDMI / HDCP：输出链路

- **EDID**：电视通过 EDID 告诉盒子自己的能力（分辨率/色彩/音频格式），盒子解析错了就会黑屏或只能输出 1080p。实验室电视机型少且都是主流新款，这类缺陷容易逃逸。
- **HDCP**：内容保护鉴权。直连电视正常、**接功放（AVR）中继后黑屏**是经典失效——只测直连不测中继链路就漏了。
- **链路裕量**：4K HDR 高带宽模式下，长的劣质线会偶发闪屏、雪点。实验室短的高质量线测不出来。
- **CEC / ARC / eARC**：联动控制与音频回传，涉及格式协商和延时补偿。

## 测试环境要求

- 电视机型库：覆盖主流品牌 + 老型号 + 带功放的组合。
- 线材矩阵：合格线 + 长劣质线。
- 分辨率/格式矩阵：1080p/4K/4K HDR × 各帧率。
