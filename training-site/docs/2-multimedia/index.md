## 先建立的整体认知

机顶盒的核心是一条**媒体处理流水线**（手册 3.3.1）：

```
传输 → 解密 → 解复用 → 解码 → 后处理 → 输出
```

测试对象是这条链路，不是某个功能点——现象出现在输出端（花屏、黑屏、无声），原因可能在任何一环。所以多媒体产品定位问题的基本功是**分层隔离实验**：接到「花屏」先问三个问题（所有频道都花吗？换 HDMI 线/电视还花吗？断网播本地文件还花吗？），每问一个排除一层。

中屏音箱则是一条端到端交互链路：采集 → 唤醒 → 识别 → 理解 → 执行 → 反馈，失败定位同样按环节切分（手册 3.4）。
