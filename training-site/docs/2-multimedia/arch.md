# 2.1 系统架构

## 六层流水线

| 环节 | 做什么 | 对应硬件/模块 | 典型失效 |
| --- | --- | --- | --- |
| 传输 | 码流从网络或射频进来 | Tuner（广播）/ IP 输入 | 丢包、组播加入失败 |
| 解密 | 解开内容保护 | DRM / CAS | 授权失败、安全等级降级 |
| 解复用 | 音视频、数据分离 | Demux | 音画错配、字幕丢失 |
| 解码 | 压缩码流还原为图像声音 | 视频/音频解码器 | 特定码流崩溃、资源泄漏 |
| 后处理 | 缩放、HDR、降噪、帧率转换 | 图像处理引擎 | 色彩异常、帧率抖动 |
| 输出 | 送到电视和音响 | HDMI、光纤、模拟音频 | EDID/HDCP 协商失败 |

## 分层定位法（必须形成肌肉记忆）

「花屏」这个词很危险——同一个现象可能来自四个完全不同的层（手册 3.3.1 提示框）：

- **网络丢包**（传输层）→ 块状马赛克，随网络波动
- **解码器 bug**（解码层）→ 特定片源必现，换片源就好
- **HDMI 链路裕量不足**（输出层）→ 闪烁、雪花点，与线材/分辨率相关
- **电源纹波**（物理层）→ 随机无规律，可能伴随其他模块异常

定位的第一步永远是做分层隔离实验，而不是查代码。

## 外部业务链路

```
运营商平台 / CDN → 家庭网关 → 机顶盒 → 电视 / 功放
```

每一环都不完全受我们控制，但出了问题用户投诉的都是机顶盒。对端包括：数千款电视机（EDID/HDCP/CEC）、功放回音壁（ARC/eARC）、运营商平台（EPG/鉴权/计费）、内容方（DRM 授权）——**互操作压力特别大**（手册 3.3.2）。

## 典型失效空间（手册 3.3.3）

EDID 解析异常（接某品牌电视黑屏）、AVR 中继 HDCP 鉴权失败、4K HDR 链路裕量不足、**音画同步漂移**（时间累积型缺陷，判据必须是趋势不是快照）、特定编码参数花屏、异常码流致解码器崩溃、解码器资源泄漏（看一晚上后换台黑屏）、高频换台组播泄漏、DRM 安全等级降级。
