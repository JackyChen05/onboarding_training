# 2.5 测试环境搭建与验收标准

## IPTV 测试环境组成

| 要素 | 内容 |
| --- | --- |
| 业务平台仿真 | 组播源（TestCenter/组播服务器）、点播服务器、EPG 服务器 |
| 网络通道 | OLT + 光猫（组播 VLAN），或直连交换机 IGMP Snooping |
| 显示终端 | 电视机型库（多品牌 + 老型号）、功放/回音壁 |
| 观测手段 | HDMI 采集卡、码流分析仪、串口/ADB 日志 |

## 中屏音箱环境

- ADB 通道：按《中屏音箱测试方法与注意事项》操作——语音禁唤醒键 + 音量- + 音量+ 各按 3 次进入 ADB 界面，用随机码 + MAC 在内部平台获取动态密码。
- 噪声环境：可控声源 + 噪声发生器，唤醒率测试需要标定声压级。
- 串口：Wi-Fi 模组日志串口（注意部分产品 ADB 与串口互斥）。

### 语音测试环境（按电信 V2.1 标准布置）

语音唤醒/识别测试对环境布置有明确要求，照搬才能复现电信判据：

- **空间布局**：噪声源（高保真音箱）距被测设备水平 2m、方位角 150°；被测设备放电视柜高约 41cm；人声发音位置在沙发高约 130cm。
- **工具清单**：待测设备 + 对比设备（竞品）、高保真音箱 ×2（一个播噪声、一个播唤醒词）、笔记本（抓日志）、分贝仪（测噪声与人声实际音量）、量角器（测噪声源方位角）、卷尺（测距离）。
- **声压级标定**：安静环境约 45dB（实验室底噪）、人声 65–70dB、家居噪声 60dB（电视+人声）、播放音乐打断场景 70–90dB——每个档位用分贝仪在设备 mic 处实测确认，不能凭感觉。
- **语料与人群**：唤醒率按成年男/女 + 儿童男/女各 50 次；识别覆盖普通话 + 粤语/上海话/西安话/成都话/长沙话/郑州话等方言。
- **网络**：时延测试要求带宽 >10M。

## 搭建验收 checklist

- [ ] 组播源发出，机顶盒能收到全部测试频道，抓包确认 IGMP 交互正常
- [ ] 点播/回看服务器可访问，RTSP 会话可建立
- [ ] 至少接入 2 个品牌电视 + 1 台功放，EDID/HDCP 协商成功
- [ ] 串口/ADB 日志通道打通，时间戳正确
- [ ] 音箱环境完成声压级标定

## 验收标准来源

1. 平台测试方案模板定义的测试范围与通过准则（见 [2.4](/2-multimedia/features) 用例资产）。
2. 过程阶段要求：《8.3 软件测试过程阶段要求-国内广电运营商》《8.4 海外运营商》（知识库「测试工作规范」）。
3. 认证类判据：杜比、HDMI、ChinaDRM 等授权认证为二值闸门，须提前锁定排期。
