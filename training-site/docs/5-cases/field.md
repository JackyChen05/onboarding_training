## 案例 1：四川电信魔方插件不回单

知识库《31、四川电信魔方插件不回单问题分析》。

现象：现网设备插件不回单（管理平台收不到设备回执）。

学习要点：

- 平台类问题的定位路径：设备侧日志（插件是否执行）→ 网络通道（抓包看回执是否发出）→ 平台侧（是否收到未处理）。
- 分段确认法：每一段先证明「我这段是好的」，再往下走——和机顶盒分层定位是同一个思想。

## 案例 3：组播返工升级（山东/河北）

知识库《山东现场组播返工升级指导书》。

现象：湖北移动机型返工发往河北移动，需组播升级到目标地区版本。

学习要点：

- 返工三流程：组播升级 → 信息核对 → 注意事项确认。
- **跨地区返工必须改地区码**，否则升级后配置不匹配；注意外部型号丢失问题。
- 工具类操作的「检查清单」意识：每一步有可验证的产出。

## 案例 4：硬件加速双路径不一致（手册重点案例）

详见 [1.5 NAT 一节](/1-access/protocols#nat：多终端共享一个公网地址)——限速不生效、流量统计对不上、端口映射时灵时不灵，根因是硬加速路径绕过软件策略。测试方法：策略类用例开/关加速各跑一遍对比。

## 案例 5：夏天下午集中掉线（手册五约束叠加案例）

高温 → 光模块功率漂移 + 高分光比光衰边界 → 信噪比不足 → OLT 判掉线。实验室常温 + 标准光衰永远复现不出来。学习要点：**应力组合测试**的必要性——单独测每个变量都正常，叠加才出问题。
