# 5.1 运营商入库测试经验

运营商入库（集采准入）测试是接入产品出货的主通道，不过 = 进不了集采——二值闸门，且周期以月计，必须在立项时锁定排期（手册 2.2.7）。

## 三家运营商的入库特点

### 中国移动

- 《10、移动入库测试经验总结_黄强》——入库流程、常见问题与对策（知识库「总结资料2」）。
- 移动特色：Andlink 智能组网、软探针插件（数据流镜像、DNS 访问信息、抓取率测试有专门方法）。
- 抓包环境：Andlink IF6 平台抓包指导（《33、andlink IF6平台抓包指导》）。

### 中国电信

- 《8、电信CTEI测试指导》——电信入库测试执行。
- 特色业务：E-link / EasyMesh 互联互通（《30、电信easymesh互联互通》）、无感配网（《28、电信无感配网测试》）、Elink 配置同步（《26、电信运营商Elink配置同步测试》- 熊锦）。
- 规范背景：《23、电信运营商规范指导》- 石才勇。

### 中国联通

- 《9、中国联通入网测试总结-V1.0》——入网全流程总结。
- 特色：功能控制平台（C 系统）测试（《联通功能控制平台测试方法指导》- 刘明）、FTTR 全屋光宽带规范（《联通FTTR进程权限最小化测试方法及说明》）。

### 通用流程

《32、电信运营商路由器入库流程》——三运营商共通的入库流程与资料准备（知识库「总结资料2」，含 5 篇文档）。

## 入库测试 vs 常规测试的差异

| 维度 | 入库测试 | 常规项目测试 |
| --- | --- | --- |
| 判据来源 | 运营商规范原文（逐条对应） | 需求 + 设计 |
| 环境 | 运营商指定拓扑/平台 | 实验室标准环境 |
| 失败代价 | 本轮入库失败，等下一轮（月计） | 版本延期 |
| 证据 | 按运营商模板出报告 | 部门报告模板 |
