# 3.6 导师签核清单（工具与仪表能力验收）

本页对应《应届生试用期能力建设与签核手册》（经验文档/07 常用测试工具），是试用期「工具签核 100%」考核的对照表。每一项能力需当面操作演示给导师，通过后在原表打 ✓ 并登记考核日期。

## 一、工具类签核（7 项）

### 1. Wireshark（抓包分析）

- [ ] 基于网卡/接口实时抓包，分析 PPPoE 拨号、DHCP 交互、ARP 解析等链路层协议交互是否正常
- [ ] 基于 IP/端口/协议（TCP/UDP/ICMP）过滤，验证防火墙 ACL 策略是否生效
- [ ] 追踪 TCP/UDP 流并导出 Payload，分析应用层数据（如 HTTP GET/POST）是否被篡改或拦截
- [ ] 使用统计工具（I/O 图表、协议分层）定位广播风暴、路由环路或异常重传问题

详细方法见 [3.1 抓包分析](/3-tools/wireshark)。

### 2. SecureCRT / ADB（串口调试与系统日志）

- [ ] 配置串口参数（波特率/数据位/停止位）连接设备 Console 口，查看 Uboot 及内核启动日志
- [ ] 中断系统自动引导，进入 Uboot/CFE 命令行，执行 tftp、flash 等命令进行固件升级或救砖
- [ ] 通过 ADB 或 SSH 登录系统，执行 logcat、dmesg、cat /var/log/messages 实时抓取系统运行日志
- [ ] 根据 Error/Fatal/Panic 关键字快速定位系统死机、重启等异常根因

详细方法见 [3.2 串口与系统日志](/3-tools/serial)。

### 3. TFTPd64 / HTTP Server / Samba（文件传输与镜像服务器）

- [ ] 搭建 TFTP/FTP/HTTP 服务器，用于路由器固件升级（tftp 刷机）及配置文件导入导出
- [ ] 模拟 HTTP/FTP 文件下载流量，测试路由器的 URL 过滤、文件类型过滤及下载限速功能
- [ ] 搭建 SMB 服务器验证路由器的 USB 存储共享、SAMBA 访问及权限控制功能
- [ ] 模拟大文件传输，测试路由器长时间高负载下的稳定性

### 4. DHCP 协议功能测试（dhcpd / dnsmasq 模拟）

- [ ] 模拟 DHCP 服务器，验证路由器 DHCP 中继（Relay）功能是否正常转发
- [ ] 模拟大量 DHCP 客户端并发请求（地址池耗尽测试），验证地址池管理及老化回收机制
- [ ] 验证 Option 字段（如 Option 150、Option 43）的自定义下发功能是否正确
- [ ] 抓包分析 DORA 流程（Discover→Offer→Request→ACK），排查地址冲突或分配异常

可用 TestCenter 模拟。Linux 下 Kea 搭建方法见 [1.8 环境搭建](/1-access/env)。

### 5. IxChariot / iPerf3（吞吐性能测试）

- [ ] 多流吞吐量测试：构造 TCP/UDP 单流及多流，分别测试上行、下行及双向全双工吞吐量，评估转发极限
- [ ] 变参压力测试：调整包长度、TCP 窗口大小及测试时长，分析不同帧长下的线速转发能力与 CPU 占用关系
- [ ] 实时指标监测：记录吞吐量曲线、平均/最大时延（Latency）、抖动（Jitter）和丢包率（Loss）
- [ ] 真实业务模拟（IxChariot 特有）：内置业务脚本模拟混合流量下的吞吐表现，验证 QoS 保障效果
- [ ] 长稳压力测试：以 90% 吞吐量压力持续运行 12~72 小时，监测吞吐波动及内存泄漏/自动降频

### 6. DVBinspector（码流分析）

- [ ] TS 流 PSI/SI 表深度解析（PAT/PMT/SDT/EIT 等），验证路由器对 IPTV/组播流表信息的透传完整性
- [ ] 按 PID 统计各码流的码率占比和空包填充率，评估视频流转发带宽占用
- [ ] 检测连续性计数错误（CC Error）、同步字节丢失（Sync Loss）及 CRC 校验错误，定位转发导致的丢包或花屏
- [ ] 识别视频编码格式（H.264/H.265）、分辨率、帧率及 GOP 结构，辅助判断 MTU/MSS 设置不当导致的播放异常
- [ ] 对比分析组播（IGMP）和单播（RTSP/HTTP-FLV）流形态差异

详细方法见 [3.3 码流/媒体分析](/3-tools/stream)。

### 7. Imatest Master（图像质量测试）

- [ ] 基础成像指标测试：MTF/SFR 锐度、畸变、横向色差、色彩还原 ΔE、噪声、动态范围、阶调响应、均匀性（渐晕/坏点）等 30 余项指标的标准化测量（符合 ISO 12233、ISO 15739）
- [ ] 多图卡兼容分析：自动解析 SFRplus、eSFR ISO、X-Rite 色卡、星点图、枯叶图等 30 余种标准测试图，单张图完成多指标同步测试
- [ ] 自动化与扩展：批量图像处理、视频帧提取、自定义测试计划、Pass/Fail 自动判定，配套数据库批量管理测试数据
- [ ] 多场景适配：消费相机、工业相机、手机影像、医疗内窥镜等成像系统，Windows/macOS/Linux 全平台

## 二、仪表类签核（5 项）

### 1. Octobox 系列（WiFi 性能测试仪表）

- [ ] 各 WiFi 协议（802.11a/b/g/n/ac/ax/be）峰值吞吐量测试，验证极限转发能力
- [ ] 多用户并发场景下的上下行吞吐量测试
- [ ] RvR（速率-距离）及 RvRvO（速率-距离-角度）测试，量化不同信号强度下的速率衰减趋势
- [ ] WiFi 协议特性验证：MU-MIMO、OFDMA、打孔等关键功能
- [ ] 同频/邻频干扰测试，评估复杂无线环境下的抗干扰能力
- [ ] TR398 Wi-Fi 性能标准测试，覆盖覆盖范围、吞吐量、稳定性全套用例
- [ ] 运营商脚本测试，覆盖各大运营商测试用例

### 2. C50（WiFi 性能测试仪表）

- [ ] 理想环境多用户吞吐量测试
- [ ] 同频/邻频干扰测试
- [ ] WiFi 多用户连接-断开压力测试，评估多设备同时连接断开稳定性
- [ ] WiFi 多用户 HTTP 下载稳定性测试

### 3. 灿芯（WiFi 性能测试仪表）

- [ ] 各 WiFi 协议峰值吞吐量测试
- [ ] 多用户并发上下行吞吐量测试
- [ ] RvR / RvRvO 测试
- [ ] WiFi 协议特性验证（MU-MIMO、OFDMA、打孔）
- [ ] 同频/邻频干扰测试
- [ ] 运营商脚本测试

### 4. C1（高层业务性能测试仪表）

- [ ] TCP 新建并发连接数测试
- [ ] 4-7 层业务相关测试

### 5. TestCenter（有线网络测试平台）

- [ ] 高速以太网性能测试
- [ ] RFC 标准基准测试（RFC 2544 等）
- [ ] 灵活的流量生成与分析
- [ ] 全面的协议仿真与功能测试
- [ ] L4-L7 应用层与安全测试

WiFi 仪表测试环境要求（屏蔽房、衰减器、转台）见 [1.6 Wi-Fi 性能](/1-access/wifi)。

## 签核流程建议

1. 按本清单逐项自学 + 实操（各工具页有方法指引）。
2. 自评能独立完成后，约导师当面演示——**演示 = 真实设备上操作，不是口述**。
3. 导师在原 xlsx 表打 ✓ 并登记考核日期。
4. 全部签核完成是试用期「认知入门」目标（30%）的硬性前置。
