# 3. 常用工具 · 模块总览与验收方式

试用期目标明确要求：以下五类工具达到**「可独立操作」级别**，按《工具能力清单》逐项由导师签核，**签核通过率 100%**。

| 工具 | 独立操作的含义 |
| --- | --- |
| [3.1 抓包分析](/3-tools/wireshark) | 独立搭建抓包环境，抓到目标报文，做出分析结论 |
| [3.2 串口与系统日志](/3-tools/serial) | 独立接线、抓日志、用日志定位问题 |

## 「可独立操作」的判定标准

不是「看过别人操作」，也不是「照着文档能做一遍」，而是：

1. **不给文档**，只给任务（例如「抓一次 PPPoE 拨号失败的报文并给出结论」），能独立完成。
2. 过程中遇到的**常规异常**（驱动不识别、抓不到包、日志没输出）能自己排查。
3. 产出物（抓包文件、日志、分析结论）符合部门规范，可直接作为缺陷证据。

## 签核方式

每个工具页面末尾有 checklist。自查全过后，约导师现场演示，逐项签核。建议第 3–6 周完成全部签核。
